## Mess Menu Recommendation System 🍲
A Java-based recommendation engine designed to suggest optimal meals from a hostel/mess menu based on student preferences, dietary restrictions, and historical ratings.
Key Features & Hybrid Approach
# Hard Filters: Filters options by diet type (VEG, NON_VEG, VEGAN), allergies, and maximum spend limits.
Content Score: Matches meals based on cuisine preferences and favorite tags.
Community Rating: Incorporates average ratings from all active students.
Collaborative Filtering: Weighs recommendations based on ratings from students with similar tastes.
Personalization: Factors in the individual student's past ratings.
## Tech Stack
Language: Java 8+
Core Concepts: Data Structures & Algorithms, Java Streams API, Date/Time API (java.time)
